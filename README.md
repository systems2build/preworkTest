# HTML Prework Exercise

A preserved, **historical educational fork** of the Vets In Tech HTML/Git prework exercise. Original source: https://github.com/MrSankofa/preworkTest

## Scope

The page illustrates semantic HTML, heading hierarchy, ordered/unordered lists, local images, and external links. It does not represent a product or current engineering capability.

## Repairs

- Added a descriptive title, viewport, semantic landmarks and a keyboard-accessible skip link.
- Replaced invalid image sizing with valid width/height attributes and image alternative text.
- Added responsive CSS and visible keyboard focus.
- Replaced personally identifiable photographs in the working tree with an abstract SVG profile. **Previous Git commits retain historical content**; removing it from history would require a separately approved history-rewrite procedure.
- Removed tracked IDE metadata and .DS_Store from the working tree.
- Added dependency-free checks through npm test; source checks are not a substitute for manual accessibility testing.

## Reproduction

Use a local static server to open index.html. Run npm test on Node 20+ to validate structural checks. The exercise intentionally retains its original films, travel list and public LinkedIn link; review that link before publishing.
